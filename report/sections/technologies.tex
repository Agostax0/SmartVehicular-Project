\section{Technologies Used}

\subsection{Simulation Environment}

\textbf{CARLA} (https://carla.org/) - The open-source autonomous driving simulator serves as the foundation for all experiments. CARLA provides:
\begin{itemize}
    \item Photorealistic urban environments
    \item Real-time vehicle dynamics and physics
    \item Rich sensor suite (RGB cameras, depth sensors, LiDAR, radar)
    \item API for scene configuration, actor management, and sensor control
    \item Synchronous simulation mode for deterministic experiments
\end{itemize}

Our implementation leverages CARLA's TCP-IP interface for external control and relies on the simulator's actor lifecycle management and sensor data streaming.

\subsection{Object Detection}

\textbf{YOLOv8} (https://ultralytics.com/) - The object detection backbone for pedestrian/cyclist recognition:
\begin{itemize}
    \item \textbf{Model variants}: YOLOv8n (nano), s (small), m (medium), l (large), x (extra-large)
    \item \textbf{Tracking mode}: \texttt{model.track()} enables persistent object IDs across frames for tracking
    \item \textbf{Object classes}: Configurable subset of COCO classes (person ID=0, bicycle=1, motorcycle=3)
    \item \textbf{Output}: Bounding boxes (xyxy format), confidence scores, class IDs, track IDs
\end{itemize}

We use the nano variant (\texttt{yolov8n.pt}) for a balance between speed and accuracy in real-time scenarios. The model processes individual frames with a configurable confidence threshold.

\subsection{Tracking Algorithm}

\textbf{Kalman Filter} - A linear dynamic model for state estimation and prediction:
\begin{itemize}
    \item \textbf{State vector}: [X, Z, Vx, Vz] - 2D position and velocity (object-relative-to-ego frame)
    \item \textbf{Measurement vector}: [X, Z] - 2D position (from depth image)
    \item \textbf{Transition model}: State evolves over time with constant velocity assumption
    \item \textbf{Control inputs}: Ego-vehicle velocities (V_ego_x, V_ego_z) for ego-motion compensation
    
    The filter performs predict-correct cycles for each object track:
    \begin{enumerate}
        \item \textbf{Predict}: Extrapolate state based on previous state and control inputs
        \item \textbf{Correct}: Update state using new measurements and compute Kalman gain
    \end{enumerate}
\end{itemize}

\subsection{Collision Assessment}

\textbf{Time-to-Collision (TTC)} - A standard metric for collision warning systems:
\begin{itemize}
    \item TTC = distance / closing_speed
    \item Closing speed computed as relative velocity between object and ego vehicle
    \item Positive TTC: object approaching; Negative TTC: object receding
    
    Our implementation uses lateral position analysis to distinguish between:
    \begin{itemize}
        \item Trajectory crossing (pedestrian in path but safe)
        \item Collision imminent (pedestrian in path and close)
        \item No risk (pedestrian moving away or far away)
    \end{itemize}
\end{itemize}

    \item Line drawing for trajectory paths
    \item Circle drawing for prediction dots
    \item Event handling for window close
    \item HWSURFACE | DOUBLEBUF for performance optimization
\end{itemize}

\subsection{CLI Framework}

\textbf{Typer} - A fast, modern command-line interface creator:
\begin{itemize}
    \item Based on type hints
    \item Automatic help message generation
    \item Support for options, arguments, flags
    \item Rich error messages and hints
    \item Asynchronous support
\end{itemize}

Usage:
\begin{verbatim}
python src/run_simulation.py \\
  --config path/to/config.yaml \\
  --scenario scenario_name \\
  --list-scenarios  # list all available scenarios
\end{verbatim}
