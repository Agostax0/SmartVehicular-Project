\subsection{Functional requirements}
Function requirements collect what the system does.
The project description defines the following requirements:
\begin{itemize}
    \item[\bf{1}] Pedestrian / Cyclist detection 
    \item[\bf{2}] Detection via front camera, depth sensor, LiDAR and sensor fusion
    \item[\bf{3}] Trajectory and collision estimation using Kalman filters
    \item[\bf{4}] Warning module based on time to collision
\end{itemize} 
\subsection{Non-functional requirements}
Non-functional requirements collect quality features the system has.
We defined our implementation to be:
\begin{itemize}
    \item [\bf{5}] Easy to configure scenarios and subsequent testing
    \item [\bf{6}] Robust in its pedestrian detection
    \item [\bf{7}] Persistent pedestrian detection when it is partially or fully occluded 
    \item [\bf{8}] Responsive in its visual output and decision-making
\end{itemize}
