Our project is an implementation of the proposed ``Project 18: Pedestrian Crossing Warning with Camera-Depth Fusion''.\\
It aims to provide a warning of possible collisions, estimations of trajectories of crossing pedestrians in a driving scenario by utilizing car sensors;
it solves this goal in 3 main phases:
\begin{itemize}
    \item pedestrian/cyclist recognition 
    \item trajectory estimation 
    \item time to collision estimation
\end{itemize}
A more in-depth analysis of the required objectives and project's goal will be explored in the following chapter.
